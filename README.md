# 工程契約變更工項擷取工具

一個純前端 HTML 工具，可從 Excel 預算書自動擷取「追加」、「追減」、「新增項目」等契約變更資料，並輸出格式化文字，供公文、簽辦、契約變更說明使用。  

供**沒有安裝 skill 的同仁**手動 copy-paste 使用；全自動產簽請用
內部工具 change-budget-verify skill（含契約資料，僅內部使用、不公開）。
兩者的概算書（明細表）計算核心是同一套邏輯，算出來的數字一致。

支援：

- 範本格式（template）
- 概算書格式（estimate，變更預算明細表 v1/v2/v3 版型）

- 支援 `.xlsx` / `.xlsm` / `.xls`
- 拖曳上傳 Excel

  - 契約變更淨額

- 純前端運作，不需後端伺服器

# 支援格式

## 1. 範本格式（template）

系統固定讀取以下工作表名稱：

| 工作表名稱 | 用途 |
|---|---|
| 原追加 | 原契約工項－追加 |
| 原追減 | 原契約工項－追減 |
| 新增 | 新增工項（須議價） |
| 新增不議 | 新增工項（不議價） |

---

# 範本格式欄位配置

系統固定讀取以下欄位：

| Excel欄位 | 欄位名稱 | 說明 |
|---|---|---|
| A | 序號 | 可空白 |
| B | 項次 | 工項代碼 |
| C | 工項名稱 | 工程項目名稱 |
| D | 原契約數量 | 原始契約數量 |
| E | 單位 | 如 M、式、座 |
| F | 單價 | 工項單價 |
| G | 數量 | 追加／追減／新增數量 |
| H | 金額 | 工項金額 |

# 範本格式範例

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 1 | 0A01 | 月台改善工程 | 10 | 式 | 100000 | 1 | 100000 |
| 2 | 0A02 | 指標更新 | 5 | 面 | 30000 | 2 | 60000 |

## 2. 概算書格式（estimate）

讀「變更預算明細表」，版型偵測與取項邏輯**整套對齊 skill change-budget-verify 的 `budget_parser.py`**，支援三種已知版型（詳細規格見該 repo 的 `docs/FORMATS.md`）：

| 版型 | 區塊標題長相 | 說明 |
|---|---|---|
| v1 | 甲／乙／丙／丁／戊（第 1 欄單一中文字） | 舊 .xls 提送版 |
| v2 | A.原有項目無追加減部分 … E.新增項目部分(不議價)（第 2 欄） | 欄位整體右移一欄 |
| v3 | 甲、原契約項目無增減部份 …（寫在工項欄） | 區塊以「小計」列收尾，012/013/014/0B 彙總只有表尾一份 |

固定欄序（相對 code 欄）：工項名稱／規格／單位／合約(數量,單價,金額)／變更(數量,單價,金額)／增減(數量,單價,金額)。

偵測不到已知版型時**直接報錯、不硬猜**（跟 skill 相同）；新版型依 skill 的 `docs/FORMATS.md` 流程處理。

---

# 概算書格式取項邏輯（對齊 skill）

- **結構化取項**：有子項的代碼＝大項，不進金額鏈（另做「大項金額 vs 子項合計」對照）；只有 leaf 工項會列出。
- 011/012/013/014/01/0B 等彙總列另存為 specials，供小計對照與金額鏈引用。
- 新增區塊依標題「(需議價)／(不議價)」自動分流，兩者都有時分「◎需議價部分／◎不議價部分」列出。
- 增減金額：增減欄優先；空白時以「變更－合約」推算；新增區塊合約側視為 0。

# 使用方式

## 方法一：直接開啟

下載 `index.html` 後直接以瀏覽器開啟即可。

```bash
index.html
```

不需安裝任何套件。

---

## 操作步驟

1. **選格式**：概算書格式（變更預算明細表，推薦——有完整驗算與金額鏈）或範本格式（四工作表）。
2. **上傳 Excel**：點擊或拖曳。其他分頁不用刪，概算書格式會自動挑「明細表」分頁。
3. **看紅字與 ⚠**：紅字＝表填與實算不符（附計算式與 Excel 列號），回 Excel 修正後重新上傳；⚠＝手打常數、大項對照等提醒。**Excel 是唯一權威，不要在輸出文字裡改數字。**
4. **複製全部文字／下載 TXT**，貼進變更簽（句型同 v5 範本，含 (四)~(八) 金額鏈）。

**一案一夾**：實際案件的預算書建議放 `projects\<案名>\`（整夾已列入 .gitignore，
含案件資料，不會進版控、也不會出現在本公開 repo）。

# 自動檢核機制（概算書格式，對齊 skill）

原則是「**預算書寫多少就是多少**」：輸出引用表列值、工具不代改數字；發現不一致就**紅字**標實算值（附計算式與 Excel 列號），由承辦人回 Excel 修正。

**紅字**（逐項/小計，附 Excel 列號）：

- 合約金額 ≠ 合約數量×單價（取 2 位截斷）
- 變更金額 ≠ 變更數量×單價（取 2 位截斷）
- 增減數量 ≠ 變更數量−合約數量；增減金額 ≠ 變更金額−合約金額
- 表列小計 ≠ 逐項加總實算
- `#REF!` 等公式錯誤儲存格（必須修，不是可忽略的空白）

**⚠ 檢查提醒**（不影響數字，請回 Excel 確認）：

- 金額欄為手打常數（脫離公式鏈；僅 .xlsx 可判斷，.xls 會明講不支援）
- 大項金額 ≠ 子項合計（大項公式範圍沒拉對）
- 0B 營業稅與變更總金額×5% 差逾 1 元

範本格式（四工作表）維持單項「單價×數量 vs 金額」稽核。

# 小數點計算原則（2026-07-10 定案）

法規並無統一規定，與機關承辦定案採以下原則（與 skill change-budget-verify 同步）：

1. **工項小計**：單價×數量所得金額，小數點二位以下**無條件捨去**（工具逐項重算，不符即紅字）。
2. **追加、追減及新增工項**：各類別分別加總後，小數點二位以下無條件捨去（各項已取 2 位，相加不生第 3 位，數學等價）。
3. **契約總價**：管理費、營業利潤、保險費等間接費用依契約約定計算，最終契約金額以**整數元**表示（承辦人 Excel 端辦理；工具不重算間接費，012/013/014/0B 一律引用表列值）。
4. **尾差調整**：尾差於營業利潤或保險費等**間接費用內吸收**，不調整直接工程費之單價或數量（工具唯讀不代改）。

# 輸出格式

概算書格式輸出完整簽稿「變更工程項目」段（句型同 v5 範本與 skill 產簽）：

```text
(一) 原契約工項追加部分：
1.項目○○○，工項名稱：○○○，原契約數量○○M，單價為○○○元，追加數量○○M，追加金額○○○元。
小計：追加○○○元。
(二) 原契約工項追減部分：（含「全數追減」句型）
(三) 新增項目：（需議價／不議價自動分流）
(四) 綜上，變更項目總合(一)~(三)：追加金額○○○元(未稅)。
(五) 包工費以外其他項目(未稅)：012／013／014
(六) 變更總金額：(四)+(五)（未稅）
(七) 變更0B營業稅(約發包工程費5％)
(八) 本次變更最終變更金額：(六)+(七)（含稅）
```

範本格式（四工作表）只出 (一)~(四) 淨額——該格式的 Excel 裡沒有 012/013/014/0B 資料，金額鏈算不出來；需要含稅最終金額請用概算書格式或 skill。

# 注意事項

## 範本格式

- 工作表名稱需完全一致
- 欄位順序不可變動
- 金額需為數字格式

---

## 概算書格式

- 版型須為 v1/v2/v3 之一（區塊標題＋固定欄序）；偵測不到會明確報錯，不硬猜
- 可接受合併儲存格、多個新增區塊（需議價/不議價）
- 其他分頁（數量計算表、單價分析表…）不用刪，會自動挑「明細表」分頁
- `#REF!` 是壞公式必須修；紅字是設計行為（截斷 vs 四捨五入的 0.01 差也會標）
