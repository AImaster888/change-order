# 契約變更工項擷取工具

一個純前端 HTML 工具，可從 Excel 預算書自動擷取「追加」、「追減」、「新增項目」等契約變更資料，並輸出格式化文字，供公文、簽辦、契約變更說明使用。  

支援：

- 範本格式（template）
- 概算書格式（estimate）

---

# 功能特色

- 支援 `.xlsx` / `.xlsm` / `.xls`
- 拖曳上傳 Excel
- 自動辨識：
  - 原契約工項－追加
  - 原契約工項－追減
  - 新增項目（須議價）
  - 新增項目（不議價）
- 自動計算：
  - 單項追加／追減金額
  - 契約變更淨額
- 自動檢核：
  - 單價 × 數量 ≠ 金額警告
- 一鍵：
  - 複製全文
  - 下載 TXT
- 純前端運作，不需後端伺服器

# 支援格式

## 1. 範本格式（template）

系統固定讀取以下工作表名稱：

| 工作表名稱 | 用途 |
|---|---|
| 原追加 | 原契約工項－追加 |
| 原追減 | 原契約工項－追減 |
| 新增 | 新增工項（須議價） |
| 新增不議 | 新增工項（不議價） |

---

# 範本格式欄位配置

系統固定讀取以下欄位：

| Excel欄位 | 欄位名稱 | 說明 |
|---|---|---|
| A | 序號 | 可空白 |
| B | 項次 | 工項代碼 |
| C | 工項名稱 | 工程項目名稱 |
| D | 原契約數量 | 原始契約數量 |
| E | 單位 | 如 M、式、座 |
| F | 單價 | 工項單價 |
| G | 數量 | 追加／追減／新增數量 |
| H | 金額 | 工項金額 |

---

# 範本格式範例

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 1 | 0A01 | 月台改善工程 | 10 | 式 | 100000 | 1 | 100000 |
| 2 | 0A02 | 指標更新 | 5 | 面 | 30000 | 2 | 60000 |

---

## 2. 概算書格式（estimate）

概算書模式不需固定欄位順序。

系統會自動搜尋：

| 關鍵字 | 用途 |
|---|---|
| 項次 / 項目 | 工項代碼 |
| 工程項目 / 工項名稱 | 工項名稱 |
| 單位 | 單位欄 |
| 數量 | 數量欄 |
| 單價 | 單價欄 |
| 金額 / 複價 | 金額欄 |
| 比較增減 | 增減欄位群組 |
| 原預算 / 合約 / 契約 | 原契約欄位群組 |
| 變更預算 | 變更後欄位群組 |

---

# 概算書格式判斷邏輯

系統會自動尋找：

- 追加區段
- 追減區段
- 新增區段

例如：

```text
(一) 原契約工項－追加
(二) 原契約工項－追減
(三) 新增項目
```

或：

```text
甲、原追加
乙、原追減
丙、新增
```

皆可辨識。

# 主要功能模組

## parseTemplate()

解析範本格式工作表：

- 原追加
- 原追減
- 新增
- 新增不議

---

## parseEstimate()

解析概算書格式：

- 自動欄位偵測
- 分區判斷
- 區段擷取

---

## fmtSec()

格式化輸出：

```text
1、項目：0A01，工項名稱：xxxx，
原契約數量10，
單價為1,000，
追加數量2，
追加金額2,000元。
```

---

## fullText()

輸出完整契約變更說明文字。

---

# 自動檢核機制

系統會自動檢查：

```text
單價 × 數量 ≠ 金額
```

若不符：

```text
【警告：單價100x數量2=200，與原表金額300不符】
```

---

# 自動排除項目

以下內容會自動略過：

- 包工費
- 承商利潤
- 品質管理費
- 營業稅
- 小計
- 合計
- 不可量化項目

以及：

```text
0A*
0B
01
```

等非實際工項資料。

# 契約變更總計格式

系統自動產出：

```text
本次契約變更總計：
(一) 原契約工項-追加 xxx 元 +
(二) 原契約工項-追減 xxx 元 +
(三) 新增項目(須議價) xxx 元 +
(四) 新增項目(不議價) xxx 元
=
本次變更淨額 xxx 元。
```

# 注意事項

## 範本格式

- 工作表名稱需完全一致
- 欄位順序不可變動
- 金額需為數字格式

---

## 概算書格式

- 可接受欄位順序不同
- 可接受合併儲存格
- 可接受多段區塊
- 建議保留：
  - 數量
  - 單價
  - 金額
  欄位名稱
