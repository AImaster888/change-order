# 契約變更工項擷取工具

一個純前端 HTML 工具，可從 Excel 預算書自動擷取「追加」、「追減」、「新增項目」等契約變更資料，並輸出格式化文字，供公文、簽辦、契約變更說明使用。  
支援「範本格式」及「概算書格式」兩種解析模式。

---

## 功能特色

- 支援 `.xlsx` / `.xlsm` / `.xls`
- 拖曳上傳 Excel
- 自動辨識：
  - 原契約工項－追加
  - 原契約工項－追減
  - 新增項目（須議價）
  - 新增項目（不議價）
- 自動計算：
  - 單項追加／追減金額
  - 契約變更淨額
- 自動檢核：
  - 單價 × 數量 ≠ 金額警告
- 一鍵：
  - 複製全文
  - 下載 TXT
- 純前端運作，不需後端伺服器

# 支援格式

## 1. 範本格式（template）

需包含以下工作表名稱：

| 工作表名稱 | 說明 |
|---|---|
| 原追加 | 原契約追加工項 |
| 原追減 | 原契約追減工項 |
| 新增 | 新增工項 |
| 新增不議 | 新增但不議價工項 |

---

## 2. 概算書格式（estimate）

支援一般工程概算書：

- 自動偵測欄位
- 自動判斷：
  - 追加區段
  - 追減區段
  - 新增區段
- 支援：
  - 分區標題
  - 多段區塊
  - 合計列停止判斷

# 主要功能模組

## parseTemplate()

解析範本格式工作表：

- 原追加
- 原追減
- 新增
- 新增不議

---

## parseEstimate()

解析概算書格式：

- 自動欄位偵測
- 分區判斷
- 區段擷取

---

## fmtSec()

格式化輸出：

```text
1、項目：0A01，工項名稱：xxxx，
原契約數量10，
單價為1,000，
追加數量2，
追加金額2,000元。
```

---

## fullText()

輸出完整契約變更說明文字。

---

# 自動檢核機制

系統會自動檢查：

```text
單價 × 數量 ≠ 金額
```

若不符：

```text
【警告：單價100x數量2=200，與原表金額300不符】
```

---

# 排除邏輯

以下類型會自動排除：

- 包工費
- 承商利潤
- 品質管理費
- 營業稅
- 合計
- 小計
- 不可量化項目

以及：

```text
0A*
0B
01
```

等非實際工項資料。

---

# 契約變更總計格式

系統自動產出：

```text
本次契約變更總計：
(一) 原契約工項-追加 xxx 元 +
(二) 原契約工項-追減 xxx 元 +
(三) 新增項目(須議價) xxx 元 +
(四) 新增項目(不議價) xxx 元
=
本次變更淨額 xxx 元。
```
